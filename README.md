# PK BATTLE ⚽

サッカーのPK（ペナルティキック）対決を、**キッカー（攻撃）**と**キーパー（守備）**の両視点で楽しめるWebゲームです。

## 遊び方（インストール不要）

`index.html` を**ダブルクリックしてブラウザで開くだけ**で遊べます。
（インターネット接続が必要です。3D描画ライブラリ Three.js をCDNから読み込みます）

### ゲームルール
- 全5本のPK勝負。あなたは**キッカーとキーパーを交互に担当**します。
- **キッカーの番**: 狙うコース（9分割）を制限時間内にタップ。同じ所を狙われ続けるとキーパーに読まれます。
- **キーパーの番**: ボールが飛んでくるコースを読んで、飛ぶ方向をタップ。
- より多く決めた（または止めた）方の勝ち。

## 公開する（任意）

GitHub Pages で無料公開できます:
1. リポジトリの **Settings → Pages** を開く
2. Source を `Deploy from a branch` にし、ブランチを選択して保存
3. 発行されたURLをスマホでも開けます

## 技術構成

- HTML + JavaScript（ビルド不要）
- [Three.js](https://threejs.org/)（3D描画、CDN読み込み）
- WebAudio API（歓声・効果音をコード生成。音声ファイル不要）
